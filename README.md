# 坦克大战 · Tank Battle

一个用原生 HTML5 Canvas 编写的经典《坦克大战》(Battle City) 复刻版，**单文件、零依赖、开箱即玩**。

## 🎮 在线试玩

> 通过 GitHub Pages 部署后，访问 `https://<用户名>.github.io/tank-battle/` 即可游玩。
> 也可以直接双击打开 `index.html` 本地游玩。

## ✨ 功能特性

- 经典 13×13 战场，砖墙、钢墙、水域、树丛四种地形
- 玩家坦克：**WASD / 方向键** 移动，**空格 / J** 开火
- 4 种敌人（普通 / 快速 / 重型 / 火力型），会主动进攻并摧毁基地
- 守护基地「老鹰」，基地被摧毁则游戏结束
- 5 种随机道具：火力强化 ★、加命 ♥、全屏炸弹 ✸、护盾 ⛨、冰冻 ❄
- 过关制：击败全部敌人进入下一关，共 3 张地图循环、难度递增
- 分数、生命、关卡、剩余敌人 HUD，最高分本地保存
- 出生无敌、护盾、爆炸粒子、屏幕震动等细节
- 音效（Web Audio，可静音），支持键盘 + 触屏操作

## 🕹️ 操作说明

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动 |
| `空格` / `J` | 开火 |
| `P` | 暂停 / 继续 |
| `M` | 静音开关 |
| `Enter` | 开始 / 下一关 / 重新开始 |

移动端（触屏设备）会自动显示虚拟方向键和开火按钮。

## 🚀 本地运行

无需安装任何依赖，直接用浏览器打开 `index.html` 即可。

## 📦 部署到 GitHub Pages

1. 在仓库 **Settings → Pages** 中，将 Source 设为 `Deploy from a branch`；
2. 选择 `main` 分支、根目录 `/ (root)`，保存；
3. 稍等片刻即可通过 `https://<用户名>.github.io/tank-battle/` 访问。
